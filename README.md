 ## Projeto SCREEN SOUD C# BACKEND

- criar nosso primeiro programa e também conhecer alguns recursos que vão nos ajudar no desenvolvimento do projeto, como por exemplo funções, listas, dicionários e leitura/escrita no console.
## OBJETIVO DO PROJETO
- desenvolver uma aplicação back-end para um sistema de músicas. Criaremos então uma aplicação de streaming com diversos artistas, bandas e músicas, mas o foco não será a parte visual, e sim o back-end da aplicação.
Dito isso, aprenderemos a armazenar músicas e a manipular determinados conteúdos, como registrar ou avaliar bandas… Faremos tudo isso com o C#!
